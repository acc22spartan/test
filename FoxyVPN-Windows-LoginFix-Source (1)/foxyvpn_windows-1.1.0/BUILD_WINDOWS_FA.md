# راهنمای ساخت نسخه ویندوز FoxyVPN

این بسته از سورس Wails/Go/React آپلودشده ساخته شده است؛ منوی فعلی و اجزای رابط کاربری عمداً بدون بازطراحی باقی مانده‌اند.

## ساخت خودکار با GitHub Actions

1. یک مخزن GitHub **جدید و خالی** بسازید؛ مخزن Flutter موجود را برای این سورس استفاده یا بازنویسی نکنید.
2. محتویات این پوشه را در شاخه `main` مخزن جدید قرار دهید؛ پوشه `.github/workflows` باید در ریشه مخزن باشد.
3. در GitHub وارد تب **Actions** شوید و گردش کار **Build FoxyVPN for Windows** را اجرا کنید. با push به `main` نیز خودکار اجرا می‌شود.
4. پس از موفقیت، از صفحه اجرای Workflow بخش **Artifacts** فایل `FoxyVPN-Windows-Build` را دریافت کنید. این بسته شامل `FoxyVPN-Setup.exe`، فایل ZIP برنامه و `SHA256SUMS.txt` است.

ساخت به Windows runner، Go 1.23، Node.js 22، Wails 2.9.2، NSIS و فایل رسمی Wintun نیاز دارد. Workflow هش SHA-256 فایل Wintun را پیش از استفاده بررسی می‌کند.

## نکته امنیتی درباره امضا

این Workflow گواهی خودامضای جعلی برای نمایش وضعیت «امضاشده و مورد اعتماد» تولید نمی‌کند. فایل‌های خروجی با گواهی ناشر تجاری امضا نشده‌اند؛ Windows ممکن است هشدار ناشر ناشناس نشان دهد.

## وضعیت تست در محیط آماده‌سازی

محیط فعلی لینوکسی به `proxy.golang.org` دسترسی شبکه نداشت؛ بنابراین دانلود وابستگی‌ها، `go test` و ساخت EXE در این محیط ممکن نشد. Workflow ویندوز ابتدا وابستگی‌ها را نصب و تست‌ها را اجرا می‌کند و تنها در صورت موفقیت به مرحله ساخت می‌رود.
